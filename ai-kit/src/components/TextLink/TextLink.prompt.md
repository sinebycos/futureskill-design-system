An inline text action — a link to another page or a small action inside/beside body text.
```jsx
<TextLink href="/courses" iconRight={<Icon name="arrow-right" />}>ดูคอร์สทั้งหมด</TextLink>
```
Tones default/neutral-strong/neutral-weak/destructive/inverse-*; size small|tiny; weight bold|regular; underline.
