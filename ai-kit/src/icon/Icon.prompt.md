Draws one Heroicons 2.2 glyph by name — the brand's only icon set; pass it into any component icon prop.
```jsx
<Icon name="academic-cap" />
<Icon name="check-circle" variant="solid" color="var(--icon-success)" />
```
Variants: outline 24 (1.5 stroke, default) | solid 24 | mini 20 | micro 16. Inherits currentColor.
